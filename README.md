# ASSALAM TAHFIZUL QUR'AN ACADEMY LIMITED 

Create a complete school result processing software exactly similar to HisGrace Gestio RPS.

The software should include:

1. Admin Dashboard

- Student management

- Teacher management

- Subject management

- Class management

- Session and term management

- Result management

- Broadsheet system

- Settings

2. Teacher Dashboard

- Enter CA scores

- Enter Exam scores

- Upload attendance

- Manage assigned subjects

3. Student Dashboard

- Check result

- Download report card

- View profile

4. Result Engine

Automatically calculate:

- Total

- Grade

- Position

- Average

- Subject highest

- Subject lowest

Grading system:

70-100 = A

60-69 = B

50-59 = C

45-49 = D

0-44 = F

5. Report Card

- School logo

- Student passport

- Principal signature

- PDF download

- Print result

6. Extra Features

- Excel import/export

- Backup & restore

- Responsive mobile design

- Dark/light mode

- Authentication system

Technology:

Frontend: React + Tailwind

Backend: Supabase

Database: PostgreSQL
